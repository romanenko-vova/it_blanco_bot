# Задание 2

1. Доделать состояния в ConvercationHandler для talk и добавить handler для info

2. Сделать игры быки и коровы по аналогии с примером для игры камень ножницы бумага

Игра должна запускаться с помощью команды /bnc и должна загадывать случайное число из 4 цифр, которое не будет содержать повторяющихся цифр.

Пользователь должен угадать это число за минимальное количество попыток.

После каждой попытки пользователь должен получать ответ, сколько цифр угаданно правильно и сколько из них стоят на своем месте.

После того как пользователь угадает число, он должен получить сообщение с количеством попыток, которое он потратил на угадывание числа.

Пример игры:

```
/bnc
Загадано число: 1234
Введите число: 2874
Ответ: 1 бык, 1 корова
Введите число: 1243
Ответ: 2 быка, 2 корова
Введите число: 1234
Ответ: Вы угадали число за 3 попытки
```
